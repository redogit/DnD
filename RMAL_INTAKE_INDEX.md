## Admission law

```text
INGESTED != ACCEPTED_AS_CANON
RELATED != SUPPORTS
COPIED != AUTHORITY_TRANSFER
CHAT_RECOVERED != VERBATIM_TRANSCRIPT
SPECIFIED != IMPLEMENTED
IMPLEMENTED != VERIFIED
VERIFIED != UNIVERSAL
```

Nothing needs to be discarded merely because it is not canonical. Preserve source identity, relation, chronology, evidence status, and unresolved remainder.
