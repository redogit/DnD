# Semantic cross-reference — directional component analysis

This document joins ideas by **technical meaning**, not by their original framing or naming.

## Core synthesis

```text
explore from a synchronized core
-> observe signed directional consequences
-> keep opposite views distinct
-> inspect cross-directions and surface-relative directions
-> vary explicit parameters
-> recursively analyze structure inside strong components
-> join only stable shared structure
-> preserve all remaining differences as residuals
-> replay the simpler core against obligations
```

## Why this is not ordinary PCA

Classical principal component analysis normally defines components through covariance structure and variance-maximizing orthogonal eigenvectors.

The current Decision Field operator asks a different question:

> Which declared direction currently explains the most **obligation-relevant** progress/evidence while accounting for residual, recovery and decay cost?

Therefore:

```text
PRIMARY_COMPONENT != MAXIMUM_VARIANCE_COMPONENT
ORTHOGONAL_RELATION != PCA_EIGENVECTOR_BY_DEFAULT
```

A conventional covariance/eigendecomposition PCA implementation may later be added as one explicit adapter/basis generator. It must not silently redefine the Decision Field component semantics.

## Downward and upward passes

The component layer naturally has two passes.

### Downward / decomposition

```text
core
-> basis
-> observations
-> projections
-> primary components
-> component-local recursive decomposition
```

This asks which distinctions are actually present inside the explored region.

### Upward / reconstruction

```text
retained component members
-> compare coordinates
-> stable shared coordinates
-> residual dimensions
-> simpler core candidate
-> replay obligations
```

This asks which structure can safely be joined again.

The two directions deliberately guard different failures:

```text
DOWN: do not alias distinct structure
UP:   do not introduce unsupported structure
```

## Surface use

For a discovered `SurfaceDefinition`:

- lateral basis tests movement **along** the surface;
- orthogonal basis tests movement **away from** it;
- diagonal bases test interactions between declared coordinate directions;
- parametric bases test explicit transform/configuration degrees;
- recursive components test whether the surface itself decomposes into internally different regions.

If the simpler core reconstructed from those views still satisfies the obligations, it may become the next core.

If not, the lost coordinate remains a residual and the core candidate is repaired or rejected.
