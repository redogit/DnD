# Decision Field operating protocol

## User-directed execution rule

The design phase established enough choices to proceed without repeatedly asking for configuration.

For ordinary local choices:

```text
recover prior accepted decisions
-> infer the smallest consistent implementation choice
-> encode the choice as an explicit rule
-> test it
-> preserve predecessor and evidence
-> continue
```

Ask again only when a genuine contradiction cannot be resolved without changing a stated invariant or user intention.

## Core execution law

```text
Obligation
-> explicit distinctions
-> candidate transforms
-> branches
-> cooperative synchronization
-> mirrors
-> overlaps
-> directional exploration
-> evidence
-> component analysis
-> simpler core candidate
-> replay / counterprobe
-> KEEP | REPAIR | UNRESOLVED
```

## Transform rules

- pure;
- replay-stable;
- exact- or obligation-reversible;
- zero, one or many declared inputs;
- zero, one or many declared outputs;
- zero-input generators capture entropy/time/external state as immutable invocation input;
- all successful invocations return status/trace/recovery information even when domain output count is zero;
- content-address identical invocations for expected O(1) reuse;
- verification against obligations is separate from cache identity.

## Branch rules

1. four primary branches execute independently;
2. all four synchronize before mirror generation;
3. mirror opposites preserve mandatory invariants and reflect declared relations;
4. pair overlap is shared supported structure, not arithmetic averaging;
5. empty overlap triggers mirror-side reexpression first;
6. concession precedes unnecessary bilateral repair;
7. a quartet succeeds on a sufficient common obligated core, not complete agreement;
8. branch-specific valid differences remain represented.

## Direction rules

- synchronized center -> 4 bounded sectors x 4 directional states = 16;
- each first-ring direction receives 12 outward executions before adaptive resource allocation;
- 16 x 12 = 192 mandatory baseline executions;
- four center-facing relations are monitoring/reference relations, not ordinary search branches;
- adaptive scheduling begins after baseline coverage;
- likely-convergent regions start separately and are regrouped at synchronization;
- low direct-progress directions may remain high-value counterprobes.

## Fix/cooperation rules

- workers share validated fixes, failures, counterexamples, concessions and residuals at synchronization;
- a fix is adopted only where its preconditions and obligations validate;
- locally valid fixes may remain scoped rather than being rejected for lack of universality;
- cohort fixes receive at least four complete synchronization rounds before preference-only supersession;
- mandatory-obligation failure may terminate a fix trial immediately;
- concession means smallest jointly sufficient change, not forced compromise.

## Depth rules

Unexpected depth is evidence.

Do not truncate a deep branch merely because it is deep.

```text
deep / drifting branch
-> preserve full lineage
-> throttle new expansion if needed
-> diagnose why the depth exists
-> locate normalized position
-> inspect homologous regions in other quadrants
-> compare repeated structure
-> reconfigure field only when evidence supports it
```

Depth intervention is adaptive to obligation-relevant information gain versus resource/recovery/decay cost.

## Triadic attack rule

Use three branches:

- pole A;
- lawful polar mirror B;
- midpoint/shared-core M.

Attack relations:

```text
A <-> B
A -> omissions in M
B -> omissions in M
M -> unsupported A-only commitments
M -> unsupported B-only commitments
```

Search distance is not predeclared.

Complete directional waves determine whether a sector-spanning `SurfaceDefinition` has appeared.

A discovered surface may define the boundary/axes of the next search region.

## Component-analysis rules

Analyze:

```text
UP / DOWN
LEFT / RIGHT
DIAGONALS
LATERAL +/-
ORTHOGONAL +/-
PARAMETRIC +/-
```

as typed bases.

Primary means obligation-relevant explanatory strength, not variance alone.

A component may become the Object of another component analysis.

Join only stable representative structure into a simpler core.

Keep every non-stable dimension as a residual with a way back.

## Evidence rules

```text
GENERATE != VERIFY != ADMIT
TRACE != PROOF
RELATED != SUPPORTS
METHOD_TRANSFER != EVIDENCE_TRANSFER
FINITE_TEST != UNIVERSALITY
REPETITION != PROOF
SUCCESS != OPTIMAL
SIMPLER != ERASED
```
