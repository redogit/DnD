# RMAL Related-File Integration Map

These files are integrated because they materially constrain, motivate, test, or provide reusable semantics for RMAL. They are **related provenance**, not automatically part of the language core.

## Relation classes

### Language semantics
- interlingua / linguistics agreement design
- carrier-surface records
- Libraries-of-Libraries bridge

Use: representation, relation, reconstruction, and cross-surface semantics.

### Decision and search machinery
- Decision Field synthesis
- all-directional relational field
- signed binary cluster carrier
- Hypothesis Algorithm Builder
- conversation-wide radar locality/parity

Use: solver/search vocabulary, distinction management, routing, bounded exploration, and path construction.

### Evidence / cooperation / authority
- Conscience64 cooperation
- REDOGIT contract
- research-production/federation/index files
- body-of-work index

Use: provenance, current-vs-historical authority, admission boundaries, cross-project relation rules.

### Domain stress-tests
- Hodge Compass API
- play/RMAO material

Use: stress-test RMAL against mathematically constrained and dynamic-world domains without granting domain truth to the language.

## Integration law

```text
RELATED_FILE
  -> PRESERVE_SOURCE_IDENTITY
  -> CLASSIFY_RELATION
  -> EXTRACT_CANDIDATE_SEMANTICS
  -> COUNTERPROBE
  -> PROMOTE_ONLY_IF_LANGUAGE_OBLIGATION_REQUIRES
```

```text
RELATED != CORE
USEFUL != AUTHORITATIVE
DOMAIN_SUCCESS != LANGUAGE_VALIDITY
LANGUAGE_SUPPORT != DOMAIN_PROOF
```
