## 3. Current 3D reversible language roguelike

**Status:** `CURRENT_LOCAL_ARTIFACT + IMPLEMENTED_BOUNDED · NOT YET REPO/CI VERIFIED`

A current browser artifact exists with a 3D reversible roguelike world and a hackable command language.

The important correction from the earlier version is that the game now interprets the intended planning language rather than exposing only a low-level API.

Current language surface includes:

```text
let directions = up, down, right, left

iff (a.move(directions) != optimal path)
    go back to choices
    and look ahead
    and pick a better one
```

The planner:

```text
DECLARE CHOICES
-> COPY WORLD STATE
-> EVALUATE LEGAL BRANCHES
-> BOUNDED LOOK-AHEAD
-> SCORE
-> RECORD REJECTED BRANCH REASONS
-> COMMIT ONE MOVE
```

`go back to choices` is therefore an explicit reversible choice-point operation, not a hidden shortcut.

Other implemented local surfaces include:

- `rewind()` over the prior complete world state;
- actor movement, attack, interaction, wait, swap, and sync functions;
- bounded look-ahead depth;
- state-aware parameter suggestions;
- searchable help/documentation;
- 3D route witnesses and world-state visualization.
