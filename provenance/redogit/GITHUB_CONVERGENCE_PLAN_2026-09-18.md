## Hard privacy gate

Public GitHub content must not silently acquire private-family or private-person context.

```text
PUBLIC_REPOSITORY != PRIVATE_FAMILY_CONTEXT
GAME_CHARACTER != PRIVATE_PERSON
SPROUTLING != REAL_CHILD
PSEUDONYM != IDENTITY_DISCLOSURE
RESEARCH_PROVENANCE != PERSONAL_DISCLOSURE
```

Rules:
- do not publish identifying/private details about family or other private people;
- do not infer real identities from fictional characters, aliases, or game forms;
- preserve only the minimum public context needed for the work;
- treat private repository identity/content as private unless explicitly promoted;
- if a task can be completed without personal context, omit the personal context.
